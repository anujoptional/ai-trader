# This is a constraints file, not a requirements file, and the difference
# matters. pyproject.toml still decides *what* gets installed; this file only
# decides *which version* of anything that does. An entry for a package the
# resolver does not select is ignored rather than forced, which is what makes a
# set captured on Windows safe to apply on the Linux runner in CI: the
# platform-conditional entries below simply go unused there.

# pytest, ruff. The rest arrive underneath them. Two are worth knowing about:
# numpy and pandas are pulled in by growwapi, not by us. AGENTS.md rules them
# out as things this codebase may *use*, and nothing in src/ imports either;
# their presence here is the broker SDK's dependency, not a loosening of that
# rule.
